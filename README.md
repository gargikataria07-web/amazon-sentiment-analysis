# Amazon Sentiment Analysis

## Project Overview
This project performs sentiment analysis on Amazon product reviews using Python. The aim is to classify customer feedback into Positive, Negative, and Neutral categories.

## Tools & Technologies
- Python
- Pandas
- TextBlob
- NLTK
- Matplotlib

## Features
- Data preprocessing and cleaning
- Sentiment analysis using TextBlob and VADER
- Visualization of sentiment distribution
- Keyword frequency analysis

## Output
- Sentiment classification of reviews
- Charts and graphs
- Processed dataset for Power BI dashboard
